# 📖 RegIntel VibeForge — User Instruction Manual

Welcome to **RegIntel VibeForge**, an enterprise-grade banking compliance and AI task automation platform. This step-by-step guide walks you through navigating the platform, processing regulatory circulars, managing team tasks, and communicating with colleagues.

---

## 🚀 1. Launching the Application

Make sure the three core components are running simultaneously:

1. **Frontend UI (React & Vite):**
   ```bash
   cd frontend
   npm run dev
   ```
   Access the web app in your browser at: **http://localhost:5173**

2. **Backend API Gateway (FastAPI):**
   ```bash
   cd backend
   source venv/bin/activate
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

3. **AI Multi-Agent Engine (Port 8001):**
   ```bash
   cd ai-agents
   source .venv/bin/activate
   python main.py
   ```

---

## 🔐 2. Authentication & Role Access

When you navigate to **http://localhost:5173**, you will see the login screen.

* **Sign In:** Enter your registered banking email and password.
* **Request Access:** New branch employees can click **"Request Access"** to submit their profile for Branch Manager / System Admin approval.
* **Roles:**
  * **System Admin / Branch Manager:** Can upload PDF circulars, approve new employees, and view global branch compliance metrics.
  * **Department Employee:** Can view assigned team tasks, download source documents, and participate in internal team chats.

---

## 📂 3. Core Workflow: Uploading & AI-Processing Circulars

When regulatory authorities (like RBI or SEBI) release complex compliance circulars:

1. Navigate to the **Regulations** or **Dashboard** view.
2. Click **Upload Circular** and select the PDF file from your local machine.
3. Once uploaded, the **FastAPI Gateway** sends the PDF bytes to the **AI Multi-Agent Pipeline**.
4. **Automated Task Slicing:** The AI engine reads the document, extracts key compliance obligations, and automatically generates departmental action items assigned to teams like **IT Security**, **Legal**, **Risk**, and **Operations**.

---

## 👥 4. Navigating Team Workspaces

To manage your department's day-to-day compliance obligations:

1. Click on **Teams** in the left navigation sidebar.
2. Select your team card (e.g., *IT Security* or *Risk & Audit*) and click **Open Team Workspace**.
3. Inside the workspace, switch between four dedicated tabs:

### ✅ Tasks Tab
* Lists all compliance tasks generated by the AI for your team.
* **Action:** Click the status checkbox on any task card to mark it as **Completed** or **Pending**. Changes sync instantly to the database.

### 📄 Documents Tab
* Displays metadata (filename, upload date) for source regulatory PDFs linked to your team's assignments.
* **Action:** Click the **Download** button on any file row to securely download the original PDF directly to your device with JWT authorization attached.

### 🏛️ Regulations Tab
* Lists the active regulatory mandates and master directives impacting your department.

### 💬 Discussions Tab
* A collaborative message feed tailored specifically to your team members for discussing compliance execution strategies.

---

## 💬 5. Internal Communications (Live Chats)

To communicate across departments and branches:

1. Click on **Chats** in the left sidebar.
2. **Left Sidebar Navigation:**
   * **Team Channels:** Listed at the top with a `#` prefix (e.g., `# it-security`, `# operations`). Click any channel to enter the shared group broadcast room.
   * **Direct Messages:** Listed underneath channels for encrypted 1-on-1 conversations.
3. **Starting a New Chat:**
   * Click the **Branch Directory** toggle tab or the **+ New Chat** button at the top right to select any branch colleague and initiate a message thread.
4. **Live Messaging:**
   * Messages appear strictly in **chronological order** (oldest at top, newest at bottom).
   * The message container automatically snaps and smooth-scrolls to the bottom whenever a new text arrives.

---

## 🛠️ 6. Administration & Oversight (Managers Only)

If logged in with administrative privileges:
* Navigate to **Settings / Approvals** (`/admin/approvals`) to review pending employee registration requests.
* Monitor live branch compliance scores and task completion ratios on the executive **Dashboard**.
